# minicoder

[![Certified Shovelware](https://justin.searls.co/img/shovelware.svg)](https://justin.searls.co/shovelware/).

Simple in-browser qualitative data analysis tool for plain-text files. Only works in [Chromium-based browsers](https://developer.mozilla.org/en-US/docs/Web/API/Window/showDirectoryPicker#browser_compatibility) that have the ability to open a folder from your local file system.
